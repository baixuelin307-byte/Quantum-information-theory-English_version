# Quantum Information Theory Notes

SOURCE:
https://cleve.iqc.uwaterloo.ca/resources/QIC-710-F26/Qic710LectureNotes2026V2.pdf



This repository contains my personal notes from studying **Quantum Information Theory / Quantum Communication**.



These notes are mainly intended for personal study, review, and understanding of the fundamental concepts of quantum communication.

> **Disclaimer:** The contents of this repository are personal study notes rather than a formal textbook or authoritative reference. Some explanations may reflect misunderstandings, lack rigor, or contain errors in the formulas. Please refer to the original textbook, research papers, and course materials for authoritative treatments.

If you notice any errors, comments and discussion are welcome.

The notes cover basic concepts such as qubits, probability amplitudes, phases, superposition, unitary operations, measurements, state discrimination, and quantum communication.
